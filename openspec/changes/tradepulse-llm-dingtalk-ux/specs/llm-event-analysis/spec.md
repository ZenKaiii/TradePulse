## ADDED Requirements

### Requirement: LLM-backed Event Analysis
The system SHALL call configured LLM providers to produce Chinese analysis for digest events.

#### Scenario: Top5 detailed analysis
- **WHEN** a digest run builds the top 10 events
- **THEN** the first 5 events include detailed Chinese summary and rationale generated by LLM
- **AND** the output includes machine-readable direction and ticker hints when available

### Requirement: Mixed Detail Output
The system SHALL generate brief analyses for lower-ranked events.

#### Scenario: Events ranked 6 to 10
- **WHEN** event rank is greater than 5
- **THEN** event analysis is generated in brief mode
- **AND** output remains concise while preserving direction and summary

### Requirement: Provider Fallback
The system SHALL prefer Bailian and fallback to Gemini when Bailian fails and Gemini credentials exist.

#### Scenario: Bailian request fails
- **WHEN** Bailian provider returns error or timeout
- **THEN** system retries via Gemini
- **AND** digest generation continues without hard failure
